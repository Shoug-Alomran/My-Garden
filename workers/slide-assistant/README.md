# SHOUG.TECH slide assistant Worker

This Worker answers questions using the prebuilt context for the current slide
or slide-breakdown page. It does not accept arbitrary source material.

## Local development

From this directory:

```bash
npm install
npm run dev
```

Workers AI inference is remote even during development and counts toward the
Cloudflare account's daily allocation.

## Deploy

```bash
npx wrangler whoami
npm run deploy
```

After deployment, attach the custom domain `ai.shoug-tech.com` to the Worker.
The browser client calls:

```text
https://ai.shoug-tech.com/v1/slide-assistant
```

The static context files are generated by
`scripts/build_ai_slide_contexts.py` during the GitHub Pages build.

The production site origins are built into the Worker as safe defaults because
they are public configuration, not secrets. `CONTENT_ORIGIN` and
`ALLOWED_ORIGINS` remain optional overrides for CLI-managed deployments.

## Security controls

- Only configured site origins receive CORS access.
- Only academic slide and slide-breakdown routes are accepted.
- Context is fetched from `shoug-tech.com`, not accepted from the visitor.
- Questions, chat history, request size, output length, and requests per minute
  are capped.
- The model is instructed to answer only from the selected source chunks.
